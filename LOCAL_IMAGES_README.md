# Локальные изображения автомобилей

## Текущие файлы в папке public/cars/

- ✅ `golf.png` - Volkswagen Golf

## Необходимые изображения

Добавьте следующие PNG файлы в папку `public/cars/`:

- `bmw-3series.png`
- `mercedes-c-class.png`
- `audi-a4.png`
- `toyota-camry.png`
- `honda-cr-v.png`
- `ford-mustang.png`
- `tesla-model3.png`

## Как добавить изображения:

1. **Найдите или создайте PNG изображения автомобилей**
2. **Сохраните их в папку `public/cars/`** с соответствующими именами
3. **Рекомендуемый размер**: 400x300 пикселей для оптимальной производительности
4. **Формат**: PNG (прозрачный фон приветствуется)

## Примеры имен файлов:

```
public/cars/
├── bmw-3series.png
├── mercedes-c-class.png
├── audi-a4.png
├── toyota-camry.png
├── honda-cr-v.png
├── golf.png ✅
├── ford-mustang.png
└── tesla-model3.png
```

## Альтернатива: Использование плейсхолдеров

Если у вас нет изображений, вы можете использовать онлайн-сервисы плейсхолдеров:

```typescript
image: 'https://via.placeholder.com/400x300/cccccc/666666?text=No+Image'
```

## Проверка работы:

После добавления изображений:
1. Перезапустите приложение: `npm run dev`
2. Проверьте, что изображения отображаются в каталоге
3. Если изображение не показывается, проверьте:
   - Правильность имени файла
   - Формат файла (должен быть PNG)
   - Путь в коде (начинается с `/cars/`)

## Советы по оптимизации:

- Сжимайте PNG файлы для уменьшения размера
- Используйте WebP формат для еще лучшего сжатия
- Добавляйте описательные alt-тексты для изображений
